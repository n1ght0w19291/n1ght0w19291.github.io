# n1ght0w1's Blog

[n1ght0w19291.github.io](https://n1ght0w19291.github.io) 的原始碼。

用 [Astro](https://astro.build) 打造的個人部落格，記錄網頁開發、軟體架構與資安相關的學習筆記與作品集。

## 這個網站有什麼

- 文章（Markdown / MDX）與圖片相簿，支援混合時間軸（`/archives`）
- Pagefind 全文搜尋（⌘K / Ctrl+K）
- Satori 動態產生 OG 分享圖
- 終端機風格的首頁 Hero、深色模式、RSS
- `/about` 頁面串接學歷、經歷、GitHub 動態等個人資訊元件

## 技術棧

Astro · React · Tailwind CSS · MDX · Pagefind · Satori · GitHub Actions（自動部署到 GitHub Pages）
